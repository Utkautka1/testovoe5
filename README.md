# Vector Illustration Composer 🎨

Интеллектуальный веб-сервис для автоматической и полуавтоматической сборки векторных композиций из библиотеки компонентов Figma с поддержкой AI-анализа метафор через DeepSeek, динамической перекраски палитр и чистого векторного экспорта в SVG.

---

## 🚀 Быстрый старт

### Требования
* Python $\ge 3.10$
* Node.js $\ge 18$

### 1. Запуск Backend (FastAPI)
```bash
# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера API (на http://localhost:8000)
python api.py
```

### 2. Запуск Frontend (Vue 3 + Vite)
```bash
cd frontend
npm install
npm run dev
# Откройте в браузере: http://localhost:5173
```

> **Примечание:** Собранный фронтенд также автоматически монтируется сервером FastAPI — при сборке `npm run build` сервис доступен целиком по единому адресу `http://localhost:8000`.

## 🏛️ Архитектура системы

### 1. Хранение и извлечение SVG-элементов
* **Изолированное векторное хранилище (`data/library/svg/`):** Все компоненты (Книга, Телефон, Наушники, Лампа, Кошелёк, Ручка, Папка, Монета, Пазлы) выгружены напрямую из Figma в векторном формате без сторонних фоновых рамок и обёрток.
* **Двойная детализация (Размеры S и L):** Для каждого объекта подготовлена детальная версия (L) для баннеров и упрощённая (S) для компактных блоков.
* **Семантическая типизация:** Объекты разделены на главные (*цветные, несущие смысл*) и фоновые (*монохромные, поддерживающие композицию*).
* **Каталог `library.json`:** Метаданные каждого объекта включают естественные габариты, соотношение сторон, категорию и массив семантических тегов для мгновенного поиска ($O(1)$ по словарю ID).

### 2. Интеллектуальный анализ метафор (DeepSeek AI)
* **Сценарий 1:** Пользователь задаёт тему или заголовок статьи (например, *«Финтех-стартап и аналитика данных»*).
* **Модель `deepseek-chat`:** Анализирует семантический контекст через строгий системный промпт, выбирает $2-4$ оптимальных объекта строго из каталога, определяет подходящую цветовую палитру и шаблон компоновки (*Собранно*, *Со смещением*, *Под заголовок*).
* **Отказоустойчивость:** При отсутствии интернет-соединения или сбое внешнего API вступает в силу эвристический семантический классификатор по тегам.

### 3. Холст и композиционный движок (Fabric.js)
* **Пропорции и форматы:** Поддержка горизонтального ($1200\times630$), квадратного ($1000\times1000$) и вертикального ($800\times1200$) форматов.
* **Манипуляции:** Свободное перемещение, вращение, масштабирование, дублирование, удаление и управление слоями (z-index).
* **Перекраска палитр:** Маппинг цветов с сохранением контраста и правил дизайн-системы.
* **Экспорт:** Выгрузка в чистый стандартизированный векторный SVG без растеризации.

## 🤖 Использованные AI-инструменты

1. **DeepSeek API (`deepseek-chat`):** Семантический анализатор заголовков и метафор, подбор ассоциативных рядов объектов и композиционных пресетов.
2. **Antigravity AI Agent:** Проектирование архитектуры по принципам Clean Architecture / SOLID, автоматическая декомпозиция функций ($\le 25$ строк) и реализация тестов.
3. **Figma MCP Server:** Инспекция макета, автоматическое извлечение и валидация векторных путей.
